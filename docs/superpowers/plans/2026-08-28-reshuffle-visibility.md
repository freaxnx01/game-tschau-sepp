# Reshuffle Visibility Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the discard-pile reshuffle observable — a toast for the local player, debug-journal entries for draws and reshuffles, and a matching toast for the P2P guest — so a legitimately recycled card no longer reads as a duplicate card (issue #13).

**Architecture:** All game logic lives in one `Component extends DCLogic` class inside a `<script type="text/x-dc">` block. `source/Tschau Sepp Online.dc.html` is the edit master; `index.html` holds a byte-identical copy of that block, regenerated by `scripts/bundle.sh` and verified by `scripts/check-dc-sync.sh` (repo-local pre-commit hook + CI `.github/workflows/dc-sync.yml`). Every task edits **only** the source file; the bundle is regenerated once, in the final task.

**Tech Stack:** Vanilla ES class component (custom `DCLogic` base, template directives `sc-if`/`sc-for`), no build step for shipping. Tests are plain Node scripts under `scripts/sim/` that extract the dc-script block from `index.html`, stub browser globals, and drive the `Component` class directly (see `scripts/sim/test-guard.mjs` for the established pattern).

**Spec:** [`docs/superpowers/specs/2026-08-28-reshuffle-visibility-design.md`](../specs/2026-08-28-reshuffle-visibility-design.md)

## Global Constraints

- Use Test-Driven Development for every task: write a failing test first, watch it fail, implement minimally to pass, verify green.
- Never hand-edit `index.html` or `support.js` — edit `source/Tschau Sepp Online.dc.html`, then run `scripts/bundle.sh` (spec: Bundle).
- The reshuffle **rule** does not change. Recycling the discard pile stays exactly as it is (spec: Scope, out of scope).
- `recycleDiscard(pile, discard)` is the single place the discard pile is recycled — no third copy of the inline recycle expression may remain (spec: § 1).
- `recycleDiscard` is pure: it does not call `setState`, does not emit toasts, and does not append journal entries (spec: § 1).
- Toast text is exactly `♻ Ablagestapel neu gmischt`; journal reshuffle text is exactly `♻ Ablagestapel neu gmischt (<n> Charte)` (spec: § 2, § 3).
- Draw journal entries are one per `drawUntilCover`/`drawCards` **call** carrying the total, never one per card (spec: § 3).
- Singular/plural in the journal: `zieht e Charte` when `n === 1`, `zieht <n> Charte` otherwise (spec: § 3).
- `debugLog` entries without a `kind` field keep rendering exactly as today (spec: § 3).
- **No code path writes the banner `message` on reshuffle**, and no `msgText` key is added — the P2P channel is the `reshuffleCount` counter only (spec: § 4).
- `debugLog` is never added to the P2P sync payload (spec: § 4).
- Swiss German UI strings, matching the surrounding voice. No i18n (spec: Scope).
- Test files are run with plain `node`; there is no test runner and nothing is installed (spec: Testing).

**Test invocation used throughout:**

```bash
node scripts/sim/test-reshuffle.mjs "source/Tschau Sepp Online.dc.html"
```

The sim scripts accept the file to extract the dc block from as `argv[2]`, defaulting to `index.html`. Passing the **source** file lets every task run its tests before the bundle is regenerated in Task 6. The extraction regex matches the `<script type="text/x-dc">` block, which exists in both files.

```js
  drawUntilCover(who) {
    const s = this.state;
    let pile = s.pile.slice(), discard = s.discard.slice();
    const hand = s.seats[who].hand.slice();
    const t = discard[discard.length - 1];
    const covers = c => c.rank === 'A' || c.rank === 'U' || c.suit === t.suit;
    const entries = [];
    let found = null, n = 0;
    while (!found) {
      if (!pile.length) {
        const rc = this.recycleDiscard(pile, discard);
        if (!rc.reshuffled) break;
        pile = rc.pile; discard = rc.discard;
        entries.push({ kind: 'reshuffle', n: rc.n });
      }
      const c = pile.pop(); hand.push(c); n++;
      if (covers(c)) found = c;
    }
    if (n) entries.push({ kind: 'draw', seat: who, n });
    const seats = s.seats.map((x, i) => i === who ? { ...x, hand, said: hand.length === 1 ? x.said : false } : x);
    this.setState({ pile, discard, seats, debugLog: s.debugLog.concat(entries) });
    if (who === s.mySeat) this.toastDraw(n);
    return { found, n };
  }
```

    const s = this.state;
    let pile = s.pile.slice(), discard = s.discard.slice();
    const hand = s.seats[who].hand.slice();
    const got = [];
    const entries = [];
    for (let i = 0; i < n; i++) {
      if (!pile.length) {
        const rc = this.recycleDiscard(pile, discard);
        if (!rc.reshuffled) break;
        pile = rc.pile; discard = rc.discard;
        entries.push({ kind: 'reshuffle', n: rc.n });
      }
      const c = pile.pop(); hand.push(c); got.push(c);
    }
    if (got.length) entries.push({ kind: 'draw', seat: who, n: got.length });
    const seats = s.seats.map((x, i) => i === who ? { ...x, hand, said: hand.length === 1 ? x.said : false } : x);
    this.setState({ pile, discard, seats, debugLog: s.debugLog.concat(entries) });
    if (who === s.mySeat) this.toastDraw(got.length);
    return got;
  }
