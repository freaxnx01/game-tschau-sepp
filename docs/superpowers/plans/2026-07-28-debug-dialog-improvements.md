# Debug Dialog Improvements Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the three Debug-dialog fixes from GitHub issue #9 — ESC-to-close, a Ctrl+Click pop-out window, and a discard-tooltip fix that names who played the card.

**Architecture:** All game logic lives in one `Component extends DCLogic` class inside a `<script type="text/x-dc">` block. `source/Tschau Sepp Online.dc.html` is the edit master; `index.html` is a generated byte-identical copy of that block, produced by `scripts/bundle.sh` and checked by `scripts/check-dc-sync.sh` (also enforced in CI, see `.github/workflows/dc-sync.yml`). Every task below edits **only** the source file, then re-bundles at the end.

**Tech Stack:** Vanilla ES class component (custom `DCLogic` base, template directives `sc-if`/`sc-for`), no build step for shipping. Test harness: plain Node scripts under `scripts/sim/` that extract the dc-script block from `index.html`, stub browser globals, and drive the `Component` class directly (see existing `scripts/sim/test-guard.mjs` and `scripts/sim/harness.mjs` for the established pattern).

## Global Constraints

- Never hand-edit `index.html` or `support.js` — edit `source/Tschau Sepp Online.dc.html`, then run `scripts/bundle.sh` (spec: scope note, all three sections).
- Solo mode (`mode === 'bot'`) only — none of these changes touch P2P (`host`/`guest`) code paths (spec: Scope).
- ESC closes the innermost open dialog in priority order: confirm-leave → Debug → Rules (spec: § 1).
- Ctrl+Click (or Cmd+Click) on the header "Debug" button opens a live pop-out window instead of the in-page overlay; a plain click keeps the in-page overlay (spec: § 2).
- The pop-out window needs no `BroadcastChannel`/`postMessage` protocol — a direct `window.open()` reference is repainted on every `renderVals()` call (spec: § 2).
- Discard tooltip label changes from `"abgleit"` to `"abgleit (<name>)"` using the existing `nm()` helper; the `otherHand` label (`"i re anderne Hand"`) is intentionally left unchanged (spec: § 3, Out of scope).

```js
// Regression tests for the Debug-dialog fixes (issue #9):
//  - discarded cards are tagged with the seat that played them
//  - the Cards-tab tooltip names that seat
//  - the ESC-priority helper picks the innermost open dialog
import fs from 'node:fs';

const INDEX = process.argv[2] || new URL('../../index.html', import.meta.url).pathname;
const html = fs.readFileSync(INDEX, 'utf8');
const src = html.match(/<script type="text\/x-dc"[^>]*>([\s\S]*?)<\/script>/)[1];

globalThis.setTimeout = () => 0;
globalThis.setInterval = () => 0;
globalThis.window = { innerHeight: 900, innerWidth: 1400 };

class DCLogic {
  constructor(props) { this.props = props || {}; this.state = {}; }
  setState(update, cb) {
    const patch = typeof update === 'function' ? update(this.state) : update;
    this.state = { ...this.state, ...patch };
    cb && cb();
  }
  forceUpdate() {}
}

const Component = new Function('DCLogic', 'StreamableLogic', 'React', src + '\n;return Component;')(DCLogic, DCLogic, {});

function newGame() {
  const c = new Component({ startcharte: '5' });
  c.state = {
    ...c.state, sound: false, mode: 'bot', difficulty: 'gwieft', mySeat: 0, roundNum: 1, starter: 0,
    seats: [
      { name: 'Du', kind: 'local', hand: [], said: false, status: 'ok', score: 0, rounds: 0 },
      { name: 'Computer', kind: 'bot', hand: [], said: false, status: 'ok', score: 0, rounds: 0 },
    ],
  };
  c.startRound();
  return c;
}

let failed = false;
function check(label, cond) {
  if (!cond) { failed = true; console.log('FAIL ' + label); }
  else console.log('PASS ' + label);
}

// --- playedBy tagging + tooltip label ---
{
  const c = newGame();
  const who = c.state.turn;
  const own = c.state.seats[who].hand.filter(x => c.canPlay(x));
  if (!own.length) {
    console.log('SKIP playedBy tagging: no playable card in this deal');
  } else {
    const played = own[0];
    c.playCard(who, played);
    const entry = c.state.discard.find(x => x.id === played.id);
    check('discard entry carries playedBy', !!entry && entry.playedBy === who);

    const vm = c.renderVals();
    const cell = vm.debugCards.find(dc => dc.label.startsWith(c.rankName(played.rank) + ' ' + c.suitName(played.suit)));
    const expectedName = who === c.state.mySeat ? 'Du' : 'Computer';
    check('tooltip label names the player', !!cell && cell.label.endsWith('abgleit (' + expectedName + ')'));
  }
}

// --- ESC-priority helper ---
{
  const c = newGame();
  c.state = { ...c.state, confirmLeave: false, debugOpen: false, rules: false };
  check('no dialog open -> null', c.topDialogToClose() === null);
  c.state = { ...c.state, rules: true };
  check('rules only -> rules', c.topDialogToClose() === 'rules');
  c.state = { ...c.state, debugOpen: true };
  check('debug + rules -> debug', c.topDialogToClose() === 'debug');
  c.state = { ...c.state, confirmLeave: true };
  check('confirmLeave + debug + rules -> confirmLeave', c.topDialogToClose() === 'confirmLeave');
}

process.exit(failed ? 1 : 0);
```

```js
  topDialogToClose() {
    const s = this.state;
    if (s.confirmLeave) return 'confirmLeave';
    if (s.debugOpen) return 'debug';
    if (s.rules) return 'rules';
    return null;
  }
  closeDebug() {
    this.setState({ debugOpen: false });
    if (this.debugPopupWin && !this.debugPopupWin.closed) this.debugPopupWin.close();
    this.debugPopupWin = null;
  }
  handleEscKey(e) {
    if (e.key !== 'Escape') return;
    const target = this.topDialogToClose();
    if (target === 'confirmLeave') this.setState({ confirmLeave: false });
    else if (target === 'debug') this.closeDebug();
    else if (target === 'rules') this.setState({ rules: false });
  }
```

```js
  openDebugPopup() {
    if (this.debugPopupWin && !this.debugPopupWin.closed) { this.debugPopupWin.focus(); return; }
    const win = window.open('', 'tschau-sepp-debug', 'width=440,height=680');
    if (!win) return; // popup blocked by the browser
    win.document.write('<!doctype html><html><head><title>Tschau Sepp — Debug</title><meta charset="utf-8"></head><body style="margin:0;background:#ede1c2;font-family:inherit;"></body></html>');
    win.document.close();
    win.addEventListener('keydown', (e) => { if (e.key === 'Escape') win.close(); });
    win.addEventListener('beforeunload', () => { if (this.debugPopupWin === win) this.debugPopupWin = null; });
    this.debugPopupWin = win;
    if (this.state.debugTab !== 'journal' && this.state.debugTab !== 'cards') this.setState({ debugTab: 'journal' });
    this.paintDebugPopup(this.renderVals());
  }
  paintDebugPopup(vm) {
    const win = this.debugPopupWin;
    if (!win || win.closed) return;
    const journalHtml = vm.hasJournalRows
      ? vm.journalRows.map(j => '<div style="padding:4px 0;border-bottom:1px solid rgba(184,146,58,0.35);">' + j.text + '</div>').join('')
      : '<div style="text-align:center;color:#8a7350;font-style:italic;">Na kei Charte gspielt disi Rundi.</div>';
    const headerHtml = vm.rankHeaders.map(rh => '<div style="text-align:center;font-size:16px;font-weight:900;color:#4a3416;">' + rh.label + '</div>').join('');
    const cardsHtml = vm.debugCards.map(dc =>
      '<div title="' + dc.label + '" style="aspect-ratio:2/3;background-image:url(' + dc.uri + ');background-size:100% 100%;border-radius:6px;opacity:' + dc.op + ';border:2px solid ' + dc.borderColor + ';"></div>'
    ).join('');
    win.document.body.innerHTML = '<div style="padding:16px 20px;font-size:14px;color:#3d3018;">' +
      '<div style="display:flex;gap:8px;justify-content:center;margin-bottom:12px;">' +
      '<button id="dbg-tab-journal" style="font-family:inherit;font-size:13px;font-weight:700;color:' + vm.journalTabColor + ';background:#fdf8ea;border:2px solid #b8923a;border-radius:8px;padding:6px 14px;cursor:pointer;">Journal</button>' +
      '<button id="dbg-tab-cards" style="font-family:inherit;font-size:13px;font-weight:700;color:' + vm.cardsTabColor + ';background:#fdf8ea;border:2px solid #b8923a;border-radius:8px;padding:6px 14px;cursor:pointer;">Charte</button>' +
      '</div>' +
      (vm.showJournalPanel ? '<div>' + journalHtml + '</div>' : '') +
      (vm.showCardsPanel ? '<div style="display:grid;grid-template-columns:repeat(9,1fr);gap:8px;">' + headerHtml + '</div><div style="display:grid;grid-template-columns:repeat(9,1fr);gap:8px;margin-top:6px;">' + cardsHtml + '</div>' : '') +
      '<div style="text-align:center;margin-top:16px;"><button id="dbg-close" style="font-family:inherit;font-size:14px;font-weight:800;color:#f6efd9;background:linear-gradient(180deg,#8a5f38,#6b4426);border:2px solid #3a2512;border-radius:10px;padding:8px 26px;cursor:pointer;">Zuemache</button></div>' +
      '</div>';
    win.document.getElementById('dbg-tab-journal').onclick = () => this.setState({ debugTab: 'journal' });
    win.document.getElementById('dbg-tab-cards').onclick = () => this.setState({ debugTab: 'cards' });
    win.document.getElementById('dbg-close').onclick = () => win.close();
  }
```

`paintDebugPopup` fully replaces `body.innerHTML` on every call rather than diffing, matching the granularity of state changes here (a few journal rows / a 36-cell grid, repainted at most once per game action) — no virtual-DOM diffing is needed at this scale.
